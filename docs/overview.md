# Event Aggregator

The `EventAggregator` is a core component responsible for managing, routing, and recording events within the system. It acts as the bridge between incoming event streams (such as MCP tool calls or HTTP payloads) and the underlying shared log recorder.

## Structure

```rust
pub struct EventAggregator {
    event_factory: EventFactory,
    global_config: GlobalConfig,
    shared_log: std::sync::Arc<AgentRecorder>,
}
```

### Key Fields
- **`event_factory`**: Responsible for constructing structured event types.
- **`global_config`**: Holds global configuration settings (e.g., database connection strings, storage backends).
- **`shared_log`**: An `Arc`-wrapped `AgentRecorder` that thread-safely records events to the configured storage backend.

---

## Thread Safety and Cloning

The `EventAggregator` implements `Clone`. Unlike previous versions where cloning an aggregator initialized a completely new recorder instance, cloning now performs a shallow clone of the `Arc<AgentRecorder>` pointer:

```rust
impl Clone for EventAggregator {
    fn clone(&self) -> Self {
        EventAggregator {
            event_factory: EventFactory::new(),
            global_config: self.global_config.clone(),
            shared_log: self.shared_log.clone(),
        }
    }
}
```

This ensures that all cloned instances of the aggregator across different threads or services (such as the MCP service and the HTTP server) write to the **same shared log instance**.

---

## Core Methods

### `new`
```rust
pub fn new(global_config: GlobalConfig) -> Self
```
Initializes a new `EventAggregator` with a shared `AgentRecorder` instance, which is automatically initialized with the provided `GlobalConfig`.

### `add_event_from_raw_stream`
```rust
pub fn add_event_from_raw_stream(
    &self,
    content: String,
    event_type: EventType,
    unix_epoch_timestamp: String,
) -> String
```
Appends an event directly to the shared log. This is particularly useful for processing raw external payloads (e.g., HTTP request bodies) that need to be parsed and logged as distinct event types.

**Returns**: `"success"` upon successfully appending the event.

# Harnesses Module

The `harnesses` module defines internal data structures used to interface with external test harnesses and agent execution environments.

## Data Structures

### `HarnessResponse`

Represents the standard JSON payload structure received from an agent execution harness.

```rust
use serde::{Deserialize, Serialize};

#[derive(Serialize, Deserialize)]
pub struct HarnessResponse {
    pub userInput: String,
    pub agentOutput: String,
}
```

#### Fields
- **`userInput`**: The raw input or prompt provided by the user to the agent.
- **`agentOutput`**: The raw response or action output generated by the agent.
```

# HTTP Response Handler

The `HTTPResponseHandler` is an Axum-compatible request handler responsible for receiving, parsing, and processing HTTP POST payloads containing agent execution results.

## Structure

```rust
pub struct HTTPResponseHandler {
    event_aggregator: EventAggregator,
}
```

---

## Core Methods

### `new`
```rust
pub fn new(event_aggregator: EventAggregator) -> Self
```
Constructs a new `HTTPResponseHandler` with the provided `EventAggregator`.

### `handle_post_response`
```rust
pub async fn handle_post_response(
    State(handler): State<Arc<Self>>, 
    body: String
) -> String
```
An asynchronous Axum stateful route handler that processes incoming POST requests. It delegates the parsing and logging logic to `process_body`.

**Returns**: `"Ok"` on success.

### `process_body`
```rust
fn process_body(&self, body: &str)
```
Parses the incoming JSON body into a `HarnessResponse`. It extracts the `userInput` and `agentOutput`, generates a current UTC timestamp, and logs both as separate events via the `EventAggregator`:
- `userInput` is logged as `EventType::UserInput`.
- `agentOutput` is logged as `EventType::AgentOutput`.

---

## Integration Example (`main.rs`)

The handler is integrated into the Axum router using shared state:

```rust
let aggregator = EventAggregator::new(config);
let http_handler = std::sync::Arc::new(HTTPResponseHandler::new(aggregator));

let router = axum::Router::new()
    .nest_service("/mcp", mcp_service)
    .route("/record", post(HTTPResponseHandler::handle_post_response))
    .with_state(http_handler);
```
